Valor entre 0 e 100. Cada autor pode convidar até este número de novos autores.

Como funciona o sistema de convites

  • • Cada autor pode convidar outros escritores para a plataforma, até o limite definido acima
  • • Um convite só é contabilizado quando o autor convidado ativa sua conta (clicando em "Aderir ao Livre Dia")
  • • Convites pendentes ou expirados não contam contra o limite do autor
  • • Autores cadastrados pelo painel administrativo não consomem convites de ninguém
  • • Se definir o limite como 0, nenhum autor poderá convidar novos autores
