📝 Regras para criar o arquivo CSS do tema

1. Nome da classe CSS: Deve ser .tema-{slug}

Exemplo: Se o slug for noturno, a classe será .tema-noturno

2. Modo escuro: Sempre inclua versão dark mode com .dark .tema-{slug}

3. Estrutura obrigatória do arquivo CSS:

/* Tema {Nome} - Descrição */
.tema-{slug} {
    background-color: #ffffff;
    color: #000000;
}

.dark .tema-{slug} {
    background-color: #000000;
    color: #ffffff;
}

⚠️ Se a classe CSS não corresponder ao slug, o tema não funcionará!
